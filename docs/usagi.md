# Usagi UI 实现基线

设计来源：用户的 `usagi-design-system/SKILL.md` 与其 `references/tokens.css`、`references/footer.html`。设计常量作为 CSS 变量纳入源码，Naive UI 共享控件从同一份 tokens 读取配色、字体和圆角，保留「温暖、可爱、纯净、现代感」基调。

| 元素 | 实现 |
| --- | --- |
| 背景 | `#FAF2E6` 奶油底色 |
| 文字 | `#3A3131`，系统中文字体栈，行高 1.7 |
| 强调 | 樱粉 `#FFB7CE`，交互深粉 `#C2597F` |
| 卡片 | 10px 圆角，暖棕轻阴影，悬浮上移 2px，键盘焦点可见 |
| 顶栏 | 与页脚同色的暖棕吸顶通栏（54px，手机 48px）：左侧站名，中间导航/博客/网盘/论坛跨站链接（当前站高亮，手机只显示图标），右侧时间与登录/管理；分类栏吸附在顶栏下方 |
| 页脚 | `#8A7A6A`，标准五站互联，当前导航站激活，安全区域适配 |
| 布局 | 根页面 Flex 列布局，内容撑开，页脚自然沉底 |

原数据中的白色默认卡片文本在奶油主题下映射为深灰棕；旧版默认半透明深灰背景改为 Usagi 浅底色，详情卡片使用白色容器；其他显式文本色和图标背景保留。图标图片无法加载时显示标题缩写。全局卡片类型与分组覆盖仍可配置。原版壁纸与搜索框自定义颜色继续支持。

验收矩阵：1920×1080、1440×900、390×844。短内容页无垂直滚动，页脚下方无留白；完整内容页自然滚动到页脚；移动端无横向溢出。额外验证键盘访问卡片、搜索筛选、访客隐藏私密分组及登录后显示全部分组。

本次优先完成导航首页和共享弹窗控件主题。管理应用仍沿用原版布局，后续可逐项将信息架构与操作方式纳入 Usagi 组件体系。
